示例文章：我是怎么搭起这个小站的

2026-10-08#建站

这是一篇示例文章，用来展示内容页的样子。想换成自己的内容，复制 posts/_template.html 改一改就行。

为什么用 GitHub Pages

想要一个能长期放东西的地方，又不想维护服务器。GitHub Pages 免费、稳定，把 HTML 文件推上去就能访问。

  • 纯静态：没有后端，也没有数据库
  • 不用构建：写好的 HTML 直接发布
  • 有版本记录：每次改动都在 git 里

整站怎么组织

首页 index.html 里有一个内容清单，每条内容占一行。新增文章就是新建一个页面，再往清单里加一行：

{type:'文章', title:'标题', desc:'一句话简介', date:'2026-10-08', url:'posts/hello.html', tags:['建站']}

所有页面共用一份样式 assets/site.css，改一处全站生效。

踩过的坑

页面之间要用相对路径引用样式，不要以 / 开头，否则换个托管位置样式就丢了。

还有一点：以下划线开头的文件不会发布出去，模板文件正好利用这一点，只在本地可见。
